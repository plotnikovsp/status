# Сторож сайтов HOME-PC снаружи

Раз в 10 минут GitHub Actions проверяет с серверов GitHub, отвечают ли сайты сервера HOME-PC (адреса — `targets.txt`).
Все остальные тревоги поднимает сам сервер, а если он выключен или пропала связь, сообщить он не может — этот сторож
нужен для такого случая.

- **Тревога** — после двух неудачных проверок подряд (каждый адрес проверяется дважды с паузой 10 с): сообщение
  в Telegram и упавший запуск, о котором GitHub присылает письмо. Пока сайты недоступны, повторных тревог нет;
  когда всё снова в порядке — сообщение с длительностью простоя.
- **Отчёт** — 1-го числа: доступность за прошлый месяц в процентах (`reports/`) и сообщение в Telegram.
- Репозиторий публичный, потому что у публичных репозиториев минуты Actions бесплатны (сторожу нужно около 4 300
  в месяц). В журнал и сообщения попадают только адреса сайтов и коды ответов; IP вырезаются, токен бота и id чата —
  только в секретах.

## Настройка Telegram

1. В @BotFather создать бота, токен — в секрет `TG_TOKEN` (Settings → Secrets and variables → Actions).
2. Нажать у бота «Старт», затем Actions → Uptime → Run workflow → `setup`: бот пришлёт ваш id.
3. id — в секрет `TG_CHAT`, затем Run workflow → `test`: должно прийти пробное сообщение.

Без секретов сторож работает, но тревога приходит только письмом от GitHub.

Новый сайт — строка в `targets.txt` (адрес, код ответа, слово на странице), только после установки сайта на сервер.
